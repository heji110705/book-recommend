# 墨韵书荐 · 部署上线指南

> 《基于混合推荐与评论情感分析的个性化图书推荐系统》生产部署说明。
> 提供三种方式：① 公网隧道（最快，适合答辩演示）；② 云服务器 Docker 部署（正式）；③ 免费 PaaS 平台。

---

## 0. 生产模式已经做了什么

| 项 | 说明 |
|---|---|
| `config/settings_prod.py` | 生产配置：`DEBUG=False`、密钥/域名走环境变量、WhiteNoise 静态服务、安全响应头（HTTPS 下自动开启 HSTS/Cookie 安全） |
| `requirements-prod.txt` | 生产额外依赖：`gunicorn`（Linux WSGI）、`whitenoise`（静态）、`psycopg2-binary`（可选 PostgreSQL） |
| `gunicorn_config.py` | Gunicorn 多进程配置（默认 3 worker，超时 120s） |
| `Dockerfile` | 单容器镜像：装依赖 → collectstatic → migrate → gunicorn |
| `docker-compose.yml` | 一键编排：`docker compose up -d --build` |
| `deploy/nginx.conf` | 可选 Nginx 反向代理参考（单容器不装 Nginx 也能跑） |

环境变量（按需）：

| 变量 | 作用 | 示例 |
|---|---|---|
| `SECRET_KEY` | Django 密钥（上线务必修改） | `z9Xq7Lm2...`（长随机串） |
| `ALLOWED_HOSTS` | 允许访问的域名，逗号分隔 | `book.example.com` |
| `CSRF_ORIGINS` | CSRF 信任的 https 来源 | `https://book.example.com` |
| `ENABLE_HTTPS` | 设为 `1` 开启 HSTS/安全 Cookie/HTTPS 跳转 | `1` |
| `DATABASE_URL` | 可选，切换 PostgreSQL | `postgres://user:pwd@host:5432/db` |

## 方式一：公网隧道，5 分钟拿到公网演示链接（推荐答辩用）

适合**临时演示**：本机跑着 Django，用内网穿透工具生成一个公网网址，评委手机/电脑都能打开。

### 1. 本机以生产模式启动

Windows 没有 gunicorn，用 `waitress`（纯 Python，可直接跑）：

```powershell
# 项目目录
cd D:\biyesheji\book_recommend
# 安装 waitress
D:\biyesheji\venv\Scripts\python.exe -m pip install waitress
# 生产模式启动（监听 8000）
$env:DJANGO_SETTINGS_MODULE="config.settings_prod"
$env:SECRET_KEY="z9Xq7Lm2vB4nK8pR3tY6wF1hG5jD0sAaUeCoiuytrWqMNBVCXZasdfghjklpoiuytrew"
$env:ALLOWED_HOSTS="*"
D:\biyesheji\venv\Scripts\python.exe -m waitress --listen=0.0.0.0:8000 config.wsgi:application
```

> 开发调试时也可直接用 `python manage.py runserver 0.0.0.0:8000`（默认 DEBUG 配置，仅供演示）。

### 2. 用 cpolar（国内、免费随机域名）开隧道

1. 注册并下载 cpolar：<https://www.cpolar.com>（免费版即可，需实名；也可换 ngrok/natapp）。
2. 安装后在本机执行（以 cpolar 为例）：

```powershell
cpolar authtoken 你的token      # 首次需配置 authtoken（在 cpolar 控制台获取）
cpolar http 8000
```

3. 终端会输出一个公网地址，形如 `https://xxxx.r6.cpolar.cn`，直接发给评委即可。
4. 首次启动若页面样式缺失，确认已执行过
   `python manage.py collectstatic --noinput`（生产模式）。

> 免费版每次重启地址会变；答辩当天开着电脑不要关即可。付费版可固定二级域名。

## 方式二：云服务器 Docker 部署（正式、可长期运行）

需要一台云服务器（阿里云/腾讯云/华为云，1 核 2G 即可，系统 Ubuntu 22.04+）。

### 1. 上传项目

```bash
# 方式 A：把整个项目（含 db.sqlite3、media 封面）打包上传
scp -r book_recommend root@服务器IP:/opt/book_recommend
```

### 2. 一键启动

```bash
cd /opt/book_recommend
# 如使用域名，先改 docker-compose.yml 中的 SECRET_KEY / ALLOWED_HOSTS
docker compose up -d --build
docker compose logs -f        # 看日志
```

访问 `http://服务器IP:8000`。

### 3.（可选）Nginx + HTTPS

`deploy/nginx.conf` 提供了参考配置。正式站点建议：
- 用宝塔面板 1Panel 或 certbot 配置域名与免费 HTTPS 证书；
- Nginx 反代到 `http://127.0.0.1:8000`，并托管 `/static/`、`/media/`；
- 开启 HTTPS 后，在 `docker-compose.yml` 设置 `ENABLE_HTTPS=1`、`CSRF_ORIGINS=https://你的域名`。

### 常用命令

```bash
docker compose restart        # 重启
docker compose down           # 停止
docker compose up -d          # 重新启动
docker compose exec web python manage.py createsuperuser   # 建管理员
```

## 方式三：免费 PaaS 平台（无需自己买服务器）

支持 Docker 的免费平台（如 [Render](https://render.com)、[Railway](https://railway.app)、[Sealos](https://sealos.io)）：

1. 把代码推到 GitHub/Gitee 仓库；
2. 平台新建 Web Service，选择该仓库，部署方式选 **Dockerfile**；
3. 设置环境变量：
   - `SECRET_KEY`：长随机串；
   - `ALLOWED_HOSTS`：平台分配的域名；
   - `CSRF_ORIGINS`：`https://平台分配的域名`；
4. 平台会自动构建并分配一个 `https://xxx.onrender.com` 公网地址。

> 免费实例休眠后首次访问较慢（30 秒内唤醒）；演示前先点开唤醒一次。

## 数据持久化说明

- 单容器镜像已内置 `db.sqlite3`（含 250 本豆瓣 Top250、100 个用户、4200+ 评分、1900+ 评论）和 `media/covers` 封面。
- `docker-compose.yml` 用 `media_data` 卷持久化上传的媒体文件。
- 演示中新增的注册/评分默认存在容器内，重建容器会重置；如需持久化数据库，可设置 `DATABASE_URL` 使用 PostgreSQL，或把 `/app/db.sqlite3` 挂载为卷。
